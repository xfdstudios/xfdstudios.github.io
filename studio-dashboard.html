XFD Studio

What it is

XFD Studio is the private, in-house analytics dashboard that XFD Studios uses to track how its own videos and posts are doing. It runs on the creator's own computer and is configured to listen only there, not on the network. It is not a public service: there are no outside users or sign-ups, and no one else's account is connected.

What it does with YouTube

When the XFD Studios YouTube channel owner signs in with Google, the dashboard asks for read-only access to that one channel:

  • YouTube Data API (youtube.readonly): reads the channel's ID and name.
  • YouTube Analytics API (yt-analytics.readonly): reads daily channel totals for the last 28 days: views, watch time, average view duration, likes, comments, shares and subscribers gained or lost.

The YouTube connection never uploads, edits, deletes, comments, or changes anything on YouTube. It uses these numbers to show charts and reports so XFD Studios can plan better videos.
